The release payloads are build inputs, never fetched or installed by awman at startup. Run `bash tools/msb-payloads/fetch.sh <target-triple>` on a native builder, then `bash tools/msb-payloads/verify.sh <target-triple>`. The committed manifest pins release archive and guest-agent hashes. Firmware is opened only by the build-time extractor to produce kernel bytes and addresses. The extracted files are ignored by the repository and must be fetched for each clean build. An unverified target remains disabled until a native run records and reviews its kernel hash and metadata. Linux also needs `bash third_party/native/libcap-ng/build.sh <target-triple>`.
